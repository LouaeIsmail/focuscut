# Focuscut clicks

Tiny Chromium extension. While Focuscut is recording, it watches clicks in other tabs and plants zooms at those points.

The website cannot see clicks on other windows by itself. This helper is how Cursorful-style auto zoom works.

## Install (unpacked)

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. **Load unpacked** and pick this `extension` folder
4. Reload Focuscut and record again

No account. No upload. Clicks stay in memory until the recording ends.
